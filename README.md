# Smart TV Remote Hub

Self-hosted веб-приложение для управления и тестирования Smart TV из браузера.

Доступны общий дашборд для нескольких LG webOS и Samsung Tizen, выбор устройства, сопряжение и виртуальный пульт. Для LG доступны выключение и включение по сети (Wake-on-LAN). Есть предпросмотр внешней вебкамеры в браузере. Поддерживается один владелец.

Samsung: реализованы авторизация, зашифрованное хранение токена, переподключение и отправка базовых клавиш через WSS. Синтетические проверки покрывают изоляцию устройств, повтор клавиш, отпускание, перезапуск и выход из аккаунта. На физическом ТВ подтверждены ответ Tizen API и событие авторизации; видимый эффект клавиш/зажатий, повторное использование сохранённого токена и регрессия LG ↔ Samsung ещё ожидают ручной проверки. Samsung Wink, каталог приложений/источников, питание и WOL пока недоступны в приложении.

Последний выход из аккаунта закрывает соединения с ТВ, сохраняя устройства и авторизацию. После нового входа выберите «Подключиться снова» в настройках ТВ. Выход одной сессии не прерывает соединения другой действующей сессии.

## Запуск

Нужен запущенный Docker Desktop. Из корня репозитория:

```sh
docker compose up -d --build
docker compose exec app node apps/api/dist/src/auth/cli.js setup-token
```

Откройте http://127.0.0.1:8080, введите одноразовый токен и создайте аккаунт. После входа откроется дашборд «Телевизоры»: выберите webOS или Tizen, добавьте включённый ТВ по частному IPv4-адресу и подтвердите доступ на его экране. Карточка открывает пульт, кнопка «Телевизоры» возвращает к списку. Токен установки нужен только для первоначального создания владельца.

Смена порта, настройка WOL, обновление и резервная копия: [инструкция Docker](docs/docker-desktop.md).

## Важно

- Сервер должен иметь доступ к локальной сети ТВ. Удалённый сервер сам по себе не обеспечивает управление домашним ТВ и WOL.
- Для включения по сети нужен MAC-адрес и подходящие настройки ТВ/сети. Отправка команды не гарантирует её физический результат.
- Не публикуйте хранилище аккаунта, ключей и резервные копии. Для обновления не используйте `docker compose down -v`: это удаляет данные.
- По умолчанию приложение доступно только на компьютере запуска. Для доступа извне нужен отдельно настроенный HTTPS и защита сети.
- Совместимость зависит от модели ТВ. При отозванном ключе возможен запрос доступа на экране даже при восстановлении связи.
- Samsung подключается к локальному HTTP API на 8001 и WSS на 8002. Самоподписанный сертификат принимается только этим Samsung-соединением; глобальная проверка TLS не отключается, перехода на WS нет. Это не удостоверяет личность ТВ и не защищает от подмены устройства в локальной сети. Отозванный Samsung-токен требует явного повторного сопряжения и подтверждения на ТВ.
- Обновление переводит SQLite на схему 5 с резервной копией перед миграцией и сохраняет LG-ключи, идентификаторы, порядок, устройство по умолчанию, MAC и аккаунт. Samsung-токены шифруются тем же хранилищем. Старый сервер откажется открывать схему 5; для отката нужны совместимая резервная копия всего каталога данных и прежняя версия сервера. Автоматического понижения схемы нет.
