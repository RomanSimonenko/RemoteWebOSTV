# RemoteWebOSTV

Open-source self-hosted веб-приложение для управления телевизорами LG webOS из браузера.

Проект находится на стадии MVP. Первая цель — подтвердить стабильное сопряжение и управление LG 43UP76906LE с webOS TV 6.5.3, затем собрать единое приложение для запуска через Docker.

## Статус

Сейчас начинается протокольный этап. Код управления телевизором ещё не считается подтверждённым до проверки на физическом устройстве.

Лицензия будет выбрана до публикации первой рабочей версии.
