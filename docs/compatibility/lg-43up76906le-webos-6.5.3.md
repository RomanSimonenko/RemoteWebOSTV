непроверенные команды и не означает готовность полного MVP.

Ключ сопряжения хранится только в локальном зашифрованном хранилище.
IP, MAC, ключи и raw payload в этот документ не включены.

доказательством пробуждения. Результат основан на повторной попытке после
подтверждённого пользователем выключения. CLI `wake: pass` означает отправку
пакета; фактическое включение в этой проверке подтверждено пользователем.

## Автоматическая проверка базового пульта — 2026-10-04

Проверены собранные UI/API, настоящая авторизация, SQLite и Lgtv2Adapter
против локального синтетического TV mock. Новых команд физическому ТВ не
отправляли; ранее подтверждённый CLI HOME не является приёмкой браузерного HOME.
Свежие проверки: `pnpm test` — 633/633 в 42 файлах, `pnpm typecheck`,
`pnpm build`, `git diff --check` — exit 0; полный Chromium E2E после сборки —
13/13 (54,9 секунды), включая пять новых сценариев пульта.

| Проверка | Результат | Доказательство |
| --- | --- | --- |
| Десять кнопок | pass, mock | Каждое нажатие даёт ровно один pointer-кадр с ожидаемым именем; command id уникальны |
| Сохранённый ТВ | pass, mock | Пульт доступен после reload, перезапуска API с тем же SQLite и logout/login без нового PROMPT |
| Нативная клавиатура Chromium | pass, mock | Десять соответствий, Shift для +, единственный Enter на кнопке; repeat, Ctrl/Alt/Meta, focus вне пульта и pending не дублируют команды |
| Защита API | pass, mock | Без сессии 401, без CSRF и с чужим Origin 403; отклонённые запросы не доходят до pointer |
| Offline и reconnect | pass, mock | Пульт блокируется, API возвращает 409 TV_UNAVAILABLE, после reconnect отправляется только новое нажатие |
| Потеря ответа после отправки | pass, mock | Настоящий API ответ удержан до получения pointer-кадра, затем HTTP-ответ прерван; UI показывает unknown, reconnect не повторяет команду |

Pointer-протокол не имеет ACK эффекта команды: после синхронного send
закрытие TV mock не может детерминированно изменить уже полученный API
результат sent. Сквозной сценарий проверяет потерю HTTP-ответа после возможной
доставки; классификация adapter not_sent/unknown отдельно проверена
интеграционными тестами. Ни один из этих результатов не доказывает эффект
кнопки на физическом ТВ.

Ручная приёмка браузерных UP, DOWN, LEFT, RIGHT, ENTER, BACK, HOME,
VOLUME_UP, VOLUME_DOWN и MUTE: **ожидается для каждой команды**. Владелец
подтвердил возможность будущего сеанса; включение ТВ и безопасный экран
ещё должны быть согласованы. Громкость проверяется малыми шагами, mute
возвращается в исходное состояние. Финальное review всей ветки тоже ожидается.
