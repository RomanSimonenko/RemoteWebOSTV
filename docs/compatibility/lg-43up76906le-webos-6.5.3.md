Дата: 2026-10-01. Решение: `use-lgtv2` для базового управления MVP.

Фактическая модель по SSAP: `43UP76906LE`. Прошивка: `03.53.45`.
Пользователь сообщил webOS TV `6.5.3`; SSAP не вернул platformVersion,
поэтому эта версия не считается автоматически подтверждённой.
Библиотека: `lgtv2@2.0.0`. Транспорт: `wss:3001`.

Обязательный шлюз для базового управления пройден: pairing, persisted
reconnect, состояние, apps/inputs, pointer и физически подтверждённая кнопка.
`lgtv2` остаётся за заменяемой границей adapter. Это решение не подтверждает
непроверенные команды и не означает готовность полного MVP.

Ключ сопряжения хранится только в локальном зашифрованном хранилище.
IP, MAC, ключи и raw payload в этот документ не включены.
