# Проверка LG 43UP76906LE

Дата: 2026-10-01. Решение: `use-lgtv2` для базового управления MVP.

Фактическая модель по SSAP: `43UP76906LE`. Прошивка: `03.53.45`.
Пользователь сообщил webOS TV `6.5.3`; SSAP не вернул platformVersion,
поэтому эта версия не считается автоматически подтверждённой.
Библиотека: `lgtv2@2.0.0`. Транспорт: `wss:3001`.

| Проверка | Результат | Доказательство |
| --- | --- | --- |
| Первичное сопряжение | pass | CLI pair завершился с кодом 0 |
| Ключ после перезапуска процесса | pass | Новый процесс check подключился с сохранённым ключом |
| Ключ после выключения и включения ТВ | pass | Пользователь перезапустил ТВ; check прошёл, повторного запроса доступа не было |
| Повторное подключение | pass | reconnect в check |
| Identity и состояние | pass | identity и snapshot в check |
| Pointer-сокет | pass | pointer в check |
| Приложения и входы | pass | apps и inputs в check |
| Определение MAC | pass | macs в check; адрес не публикуется |
| Кнопка HOME | pass | button в CLI; пользователь подтвердил открытие главного экрана |
| Уведомления | pass | notification в CLI; пользователь подтвердил появление тестового уведомления |
| Выключение через API | pass | power-off в CLI; пользователь подтвердил выключение ТВ |
| Wake-on-LAN | pass, подтверждено вручную | Пользователь выключил ТВ обычным пультом; после отправки magic packet подтвердил включение. MAC задан пользователем, автоматическая связь с identity не доказана |
| WS fallback | не проверено | На стенде успешно выбран WSS |

Обязательный шлюз для базового управления пройден: pairing, persisted
reconnect, состояние, apps/inputs, pointer и физически подтверждённая кнопка.
`lgtv2` остаётся за заменяемой границей adapter. Это решение не подтверждает
непроверенные команды и не означает готовность полного MVP.

Ключ сопряжения хранится только в локальном зашифрованном хранилище.
IP, MAC, ключи и raw payload в этот документ не включены.

Первая отправка Wake-on-LAN выполнялась на уже включённом ТВ и не считается
доказательством пробуждения. Результат основан на повторной попытке после
подтверждённого пользователем выключения. CLI `wake: pass` означает отправку
пакета; фактическое включение в этой проверке подтверждено пользователем.
