# Компактный пульт — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Перенести согласованный компактный макет в приложение.

**Architecture:** Изменяются только разметка Remote и её CSS. Обработчики команд, удержание, питание и статус остаются прежними.

**Tech Stack:** React, TypeScript, CSS, Tabler, Playwright.

**Spec:** Согласованный в чате компактный макет: ширина корпуса 272 px, радиус 40 px, цифровые и навигационные кнопки 48 × 48 px; навигация «Домой / Вверх / Назад», «Влево / OK / Вправо», «пусто / Вниз / пусто»; нижние блоки той же ширины 156 px, что верхние.

## Global Constraints

- Не менять API, команды, авторизацию, удержание и доступность кнопок.
- Использовать существующие Tabler-иконки.
- Не отправлять команды настоящему ТВ при автоматической проверке вёрстки.

## Review Focus

- Узкий экран 320 px: отсутствие горизонтального переполнения.
- Широкий экран: корпус не растягивается.
- Home/Back: команды и доступные названия сохраняются после переноса.
- Питание: подтверждение остаётся рядом с кнопкой и не выходит за экран.
- Отключённый ТВ: положение корпуса не зависит от статуса.
