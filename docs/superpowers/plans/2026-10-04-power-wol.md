# Питание/WOL — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Выключать сохранённый ТВ и пробуждать его из браузера с ограниченным восстановлением соединения без replay.
**Architecture:** Существующий TV Service остаётся единственным владельцем admission, поколений соединения и отмены. Общие контракты описывают питание; adapter выполняет SSAP/WOL, repository сохраняет MAC, API защищает операции, UI отображает серверное состояние.
**Tech Stack:** TypeScript, Zod, Fastify, SQLite/better-sqlite3, React, Vitest, Playwright, существующий lgtv2; без новых зависимостей.
**Spec:** `docs/superpowers/specs/2026-10-04-power-wol-design.md`, утверждена пользователем 2026-10-04.

## Global Constraints

- Общий срок восстановления по умолчанию 60 секунд, включая попытки; никакого автоматического WOL или replay команд.
- Автоматическое подключение использует сохранённый ключ и никогда не запрашивает сопряжение.
- Выключение требует явного подтверждения; транспортный результат не доказывает физический эффект.
- Старые настройки без MAC поддерживаются; реальные адреса, ключи и аккаунт не попадают в артефакты.
- Пульт из десяти кнопок, текущие auth/Origin/CSRF/no-store и публичные ошибки сохраняют контракт.
- Выход инициирующей сессии, отмена и shutdown освобождают ресурсы. Перезапуск не возобновляет старую операцию.
- Дизайн, discovery, облачный сервис и постоянный фоновый reconnect не входят.
- Время и конкурентность в тестах управляются scheduler/barriers; не использовать реальные ожидания для доказательства гонок.

## Review Focus

1. Смена адреса другого физического ТВ не сохраняет неподтверждённый MAC как действительный — Task 1.
2. Потеря HTTP-ответа после принятия операции не вызывает повторный побочный эффект — Tasks 3–4.
3. Таймаут не освобождает admission раньше завершения owned cleanup — Task 2.
4. Поздний ответ старого поколения не перезапускает цикл после намеренного выключения — Task 2.
5. Logout одной вкладки отменяет только работу инициирующей сессии, автоматическая работа имеет серверного владельца — Task 3.
