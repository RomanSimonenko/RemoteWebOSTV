# Компактный интерфейс: план реализации

Текущий статус 2026-10-05: исходный компактный интерфейс опубликован и слит через PR #6; дальнейший цифровой блок и индикаторы — PR #8. Записи «PR пока не создан» ниже относятся к историческому моменту проверки. Текущая спецификация дополнена каналами/цветными кнопками, удержанием только стрелок и громкости, радиусом 40 px и логотипом 60 × 28 px. Полный прогон удержания: 936 тестов и 50 браузерных сценариев; новая аппаратная приёмка удержания ещё не выполнена. Актуальные следующие шаги отражены в общем roadmap.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Реализовать согласованный универсальный пульт и настройки отдельным окном без изменения серверных контрактов.

**Architecture:** `TvSetup` сохраняет владение подключением. Один постоянно смонтированный `PowerControls` сохраняет `useTvPower`; его формы MAC выводятся в окно настроек через portal, без второго хука. `Home` владеет открытием окна и кнопкой в шапке; закрытие меняет только представление.

**Tech Stack:** React 19, TypeScript, CSS, Vitest/Testing Library, Playwright; без новых зависимостей.

**Spec:** `docs/superpowers/specs/2026-10-04-unified-remote-ui-design.md`.

## Global Constraints

- Одна кнопка питания, действие только по `canPowerOff` / `canWake`, выключение требует подтверждения.
- Настройки вне пульта, в шапке рядом с выходом; окно не сдвигает карточку.
- Сетевой статус не доказывает физическое состояние экрана.
- Существующие команды, API, авторизация, ограничения и восстановление сохраняются.
- Ширина от 320 px, видимый фокус, русский интерфейс; никакой передачи изображения ТВ.
- Только синтетические данные в тестах и артефактах; не читать пользовательские ключи.
- Рабочее приложение не пересобирать на месте: проверки и сборку выполнять в изолированной копии без `.local`.

## Review Focus

1. Закрытие окна во время операции не размонтирует владельца и не отменяет запрос: задача 2.
2. Escape/Enter/стрелки и Tab в окне не отправляют команды ТВ: задача 2 и 3.
3. Ошибка загрузки, нет MAC или противоречивые разрешения не выбирают действие питания наугад: задача 1.
4. Истечение сессии, выход и первичная настройка сохраняют очистку и доступность: задача 2 и 3.
5. Длинная диагностика и узкая ширина не перекрывают кнопки и не создают горизонтальную прокрутку: задача 3.
