# Навигация по документации

- [Docker Desktop на Mac](docker-desktop.md) — локальный контейнерный запуск, постоянные данные, обновление и резервная копия.
- [README проекта](../README.md) — краткое описание, быстрый запуск и основные ограничения.
- [Разработка и запуск без Docker](development.md) — локальный запуск, конфигурация и команды проверок.
- [Базовое ТЗ](superpowers/specs/2026-09-02-remote-webos-tv-mvp-design.md) — целевой объём MVP; наличие требования не означает, что оно уже реализовано.
- [Дорожная карта](superpowers/plans/2026-09-02-remote-webos-tv-mvp-roadmap.md) — состояние этапов и оставшаяся работа. Датированные отчёты внутри неё являются историей.
- [Актуальный интерфейс](superpowers/specs/2026-10-04-unified-remote-ui-design.md) — согласованные расположение, размеры и поведение пульта. Эта спецификация заменяет прежние описания макета.
- [Дашборд](superpowers/specs/2026-10-07-dashboard-design.md) — стартовый экран после входа, переход к текущему ТВ и границы первого этапа.
- [Проверки физического ТВ](compatibility/lg-43up76906le-webos-6.5.3.md) — аппаратные результаты и границы подтверждённой совместимости.
- [Направление тестового стенда](proposals/2026-10-06-webos-test-bench.md) — согласованное назначение продукта и будущее расширение с вебкамерой; видеопоток пока не реализован.

Остальные документы в `superpowers/plans` сохраняют задачи и свидетельства конкретных этапов. Их старые параметры макета, команды последующих действий и числа тестов не следует принимать за текущее состояние. Спецификации сопряжения, базового пульта и питания сохраняют соответствующие контракты; поздние уточнения интерфейса находятся в актуальной UI-спецификации.

Кнопка «Источники» и пользовательский выбор источника исключены из плана. Исторические протокольные проверки входов сохранены как технические свидетельства.
